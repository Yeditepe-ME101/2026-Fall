Activity 2: Group Discussion

  • Select a topic/keyword that you found interesting in the lecture activity or the tag cloud below, and write it in your file that was created in the previous step.
  • Communicate with the instructor and reach an agreement upon a mutually agreed keyword.
  • Search the internet about the keyword/topic using the resources described in the previous activity.
  • Make a list of at least 5 references relevant to the keyword, 3 of which are from peer-reviewed sources.
  • From each of the 5 references, find a sentence that outlines/summarizes the relevant focus topic.

Activity 3: Documentation

  • Here, you will carry your work to Overleaf
  • All Group Members opens accounts in Overleaf
  • Group Secretary creates a document from a Blank Template
  • Group Secretary shares editable document links with other members
  • Copy/paste the bibtex citations to a separate bibliography (.bib) file in Overleaf
  • In the main file (main.tex) use the \begin{quote} environment to copy/paste the five sentences from each reference
  • Add relevant citations to each quote using the \cite{} key
  • Add a title and subtitle to your document
  • Add the names of group members as authors
  • Compile and create a PDF.
